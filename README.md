# To-Do List App

A simple to-do list with add, edit, delete and mark-as-done. Tasks are saved in your browser's local storage.

**Live demo:** https://umar8092.github.io/todo-list-app/

## Use it

Download or clone the repo and open `index.html` in a browser. No build step or dependencies.

```
git clone https://github.com/umar8092/todo-list-app.git
```
